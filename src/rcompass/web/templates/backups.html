복구하기

복구는 서버를 끈 상태에서 명령줄로 합니다. 빈 데이터 폴더를 지정하면 그 폴더에 그대로 복구됩니다.

rcompass restore <백업 zip 경로> --data-dir <빈 폴더>
  • 레코드 수와 모든 파일의 sha256이 백업과 같은지 확인한 뒤에만 데이터를 바꿉니다.
  • 이미 기록이 있는 폴더는 거부합니다. --force를 붙이면 기존 데이터를 먼저 백업하고 바꿉니다.
  • 이전 버전 앱의 백업이면 최신 스키마로 올립니다. 끝나면 외부 참조마다 "접근 가능", "없음", "지문 불일치"를 알려줍니다.

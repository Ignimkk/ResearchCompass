# Claude Code 연동

연구 나침반은 외부 LLM API 없이 동작합니다. Claude Code와는 텍스트 두 가지로 주고받습니다.

1. **인계 문서**: 프로젝트 홈의 "Claude Code 인계"(또는 `rcompass handoff <프로젝트 번호>`)로 만든 Markdown을
   새 Claude Code 세션의 첫 메시지에 붙여넣습니다. 연구 질문, 성공 기준, 현재 기준선, 기각한 접근, 다음 행동과
   결과 보고 형식이 들어 있습니다. 특정 실험의 결과를 받으려면 `--experiment E3`(화면에서는 실험의 "이 실험용 인계 문서")를 씁니다.
2. **결과 블록**: Claude Code가 실험을 마치고 출력한 ```` ```rcompass-result ```` 블록을 실험 화면의
   "Claude Code 결과 붙여넣기"에 붙여넣습니다. 미리보기에서 값을 확인하고 고친 뒤 "확인하고 기록"을 눌러야 저장됩니다.

## 연구 저장소에 넣을 것

둘 중 하나를 고르세요.

**스킬로 넣기**: 이 폴더의 `rcompass-result/`를 연구 저장소의 `.claude/skills/rcompass-result/`로 복사합니다.

**CLAUDE.md에 두 줄 넣기**: 연구 저장소의 `CLAUDE.md`에 다음을 붙여넣습니다.

```markdown
- 실험을 마치면 연구 인계 문서의 "결과 보고 형식"대로 `rcompass-result` 블록 하나로 결과를 보고한다. 실제로 얻은 값만 적는다.
- 연구 인계 문서에서 기각되거나 철회된 접근은 그 이유가 해소되었다는 근거가 없으면 다시 제안하지 않는다.
```
